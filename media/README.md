# media/

Assets activos del catálogo web, ordenados por arquitectura del sitio.

- `brand/` — logos, portada, thumbs
- `perfiles/` — secciones técnicas de perfil
- `fichas/` — PDFs de descarga
- `aplicaciones/{luminarias,lightbox,totems,aereos,vestimos,rigidos}/`

Todo lo histórico o no usado está en `../revisar/` (no borrar).
